# PENTA — ギター・ペンタトニック暗記

ギターのペンタトニックスケールを暗記するためのシングルページWebアプリです。HTML/CSS/JavaScript を `index.html` 1ファイルにまとめて構成しています。

## 特徴

- ティール色＝スケール音、ゴールド色＝ルート音で視覚的に把握
- ビルド不要・依存ゼロ（静的HTMLのみ）

## モード

| モード | 内容 |
| --- | --- |
| 学習 | ペンタトニックの5ポジションを指板で確認する |
| トライアド | ペンタの中の3音（1・3・5）を色で浮かび上がらせる |
| クイズ | ハイライトされた音の度数・音名を当てる |
| コード | コード38種の押さえ方と、コードトーン⇄ペンタの対応を見る |
| トーン | コードトーンだけを指板に表示し、押さえ方と度数をセットで覚える |
| ソング | 曲のコード進行チャートを再生する |

## トライアドモード（アドリブでコード感を出す）

ペンタトニックの5音のうち、**コードそのものである3音（1・3・5）**を色で浮かび上がらせるモードです。

- **3段階の色分け** — ルート＝濃い黄／3rd・5th＝茶（薄く色つき）／残りのペンタ＝暗いグレー（数字だけ）
- **「トライアドだけ」トグル** — 残り2音を指板から消して、3音だけにする
- **5つのフォーム** — 各ポジションに CAGED のフォーム名（E・D・C・A・G）とルート弦を表示
- **コード進行チャート** — マイナーブルース／メジャーブルース／II-V-I／カノン／王道／小室進行。コードをタップすると、そのコードのトライアドに切り替わる
- **覚えるべきポイント7項目**と**つまずきポイント5項目**

### 考え方

ペンタ1発で通すとどのコードでも同じ響きになります。コードが変わったらトライアドも切り替える——これがコード感の正体です。まずルートの位置を「探さずに分かる」状態にし、次に3rd・5thを足し、残りのペンタは通り道として使います（着地しない音と決めておく）。

## トーンモード（コードとコードトーンをセットで覚える）

コード38種（トライアド／セブンス／6th・add／9th／11th・13th／オルタード）に対応。

- 指板にはコードトーンだけを表示し、**R＝金／3rd＝ピンク／5th＝青／7th＝紫／テンション＝ティール**で役割ごとに色分け
- 表示範囲は「ボックス（ペンタのポジション窓）／フォーム（6弦・5弦・4弦ルート起点）／全フレット」
- **押さえ方ダイアグラムの丸に度数を表示** — 指番号ではなく「その音がコードの何番目か」を指板と同じ色で描くので、押さえ方とコードトーンを同時に覚えられる。タップで音が鳴る
- **度数の役割表** — R / 3rd / 5th / 7th / テンションが「どんな役割の音か」を1行で説明
- 「ペンタ重ね」でコードトーンがペンタトニックのどの音と重なるかを確認
- 「クイズ」でコードトーンの度数当て（9th・11th・13thを含む）

### 学べる規則性

1. **コードトーンとは何か** — そのコードを作っている音そのもの。伴奏で鳴っているコードのコードトーンは、いつ弾いても外れない
2. **積み方は「1つ飛ばし」だけ** — ド →(レを飛ばす)→ ミ →(ファを飛ばす)→ ソ →(ラを飛ばす)→ シ ＝ Cmaj7。使っていない段は点線で表示
3. **指を1本ずらすだけで別のコードになる** — Cmaj7 の「シ」を半音下げると C7、さらに「ミ」を下げると Cm7。チェーン7系統をボタンで行き来できる
4. **指板での見つけ方** — R の探し方、オクターブ（2本細い弦の2フレット上）、3rd・5th・7th の位置関係

## ローカルで開く

```bash
open index.html
```

## デプロイ

Vercel で静的サイトとしてホスティングしています。公開URL: https://guitar-pentatonic.vercel.app

**GitHub 連携は未設定なので、`git push` だけでは反映されません。** CLI から本番へ反映します。

```bash
npx vercel --prod
```

デプロイ履歴の確認は `npx vercel ls`。

> 補足: Vercel の Security Checkpoint（Bot対策）が有効なため、`curl` やヘッドレスブラウザでは公開URLの中身を取得できません。反映確認は実ブラウザで行ってください。
