# PENTA — ギター・ペンタトニック暗記

ギターのペンタトニックスケールを暗記するためのシングルページWebアプリです。HTML/CSS/JavaScript を `index.html` 1ファイルにまとめて構成しています。

## 特徴

- ティール色＝スケール音、ゴールド色＝ルート音で視覚的に把握
- ビルド不要・依存ゼロ（静的HTMLのみ）

## モード

| モード | 内容 |
| --- | --- |
| 学習 | ペンタトニックの5ポジションを指板で確認する |
| クイズ | ハイライトされた音の度数・音名を当てる |
| コード | コード38種の押さえ方と、コードトーン⇄ペンタの対応を見る |
| トーン | コードトーンだけを指板に表示し、アルペジオで音階練習する |
| ソング | 曲のコード進行チャートを再生する |

## トーンモード（コードトーンの音階練習）

コード38種（トライアド／セブンス／6th・add／9th／11th・13th／オルタード）に対応。

- 指板にはコードトーンだけを表示し、**R＝金／3rd＝ピンク／5th＝青／7th＝紫／テンション＝ティール**で役割ごとに色分け
- 表示範囲は「ボックス（ペンタのポジション窓）／フォーム（6弦・5弦・4弦ルート起点）／全フレット」
- **運指タブ譜** — 弾く順番・フレット・指番号（1=人差し指〜4=小指、0=開放弦）を表示し、再生に合わせて光る。手の位置を移動する箇所は破線で示す
- **練習パターン** — 上昇／下降／往復／1つ飛ばし／3連シーケンス
- アルペジオ再生（BPM 40〜200、ループ可）と**メトロノーム**
- 「ペンタ重ね」でコードトーンがペンタトニックのどの音と重なるかを確認
- 「クイズ」でコードトーンの度数当て（9th・11th・13thを含む）

### フロー練習（コードを繋げて流す）

コード進行を連続再生し、**コードが変わるたびに直前の音にいちばん近いコードトーンから弾き始める**（ボイスリーディング）。フレット位置は表示中の範囲に固定されるので、手が飛ばずひと続きのフレーズとして繋がります。

進行プリセット7種: `maj7 → 7 → m7` ／ `II-V-I` ／ `I-VI-II-V` ／ ブルース ／ カノン ／ 王道進行 ／ スリーコード。1コードあたり4音か8音を選択。

窓の幅は「手を動かさずに押さえられる範囲」に制限しています（広げると1弦に3音以上出て運指が破綻するため）。

### 学べる規則性

1. **3度堆積** — R→3→5→7→9→11→13 はスケールを1つ飛ばしに積んだもの。空欄の段＝省略している音
2. **半音ひとつでコードが変わる** — `maj7 →(7thを半音↓)→ 7 →(3rdを半音↓)→ m7 →(5thを半音↓)→ m7♭5 →(♭7を半音↓)→ dim7` などのチェーンを7系統
3. **指板の位置の規則** — オクターブは「2本細い弦・2フレット上」、♭7はルートの2フレット下、9thは2フレット上、など
4. **コード構成音 早見表** — 全38種 × 12音の一覧。行をタップでそのコードに切り替わる

## ローカルで開く

```bash
open index.html
```

## デプロイ

Vercel で静的サイトとしてホスティングしています。公開URL: https://guitar-pentatonic.vercel.app

**GitHub 連携は未設定なので、`git push` だけでは反映されません。** CLI から本番へ反映します。

```bash
npx vercel --prod
```

デプロイ履歴の確認は `npx vercel ls`。

> 補足: Vercel の Security Checkpoint（Bot対策）が有効なため、`curl` やヘッドレスブラウザでは公開URLの中身を取得できません。反映確認は実ブラウザで行ってください。
